i want to add temporal theming to the app stack. the primary use case is seasonal/holiday theming.

- user configurable holiday schedule, default to standard US holidays. examples
    - christmastime - for a user-definable calendar time, themes change to red/green with fun christmas theming. (same with holidays for every culture/tradition, and around the year for special major celebrations)
    - fourth of july - we're american, make red white and blue and streamers and fireworks for 7/4
- birthdays
    - on family members' birthdays, the kiosk ui changes to feature pictures of the family member prominently
- ad-hoc
    - an admin can push a theme or image/album as an ad-hoc theme for a specified time period
